Each vertex of the tree is labeled either zero or one. Unfortunately, Maple forgot how the vertices are labeled and only remembers that there are exactly $$$k$$$ zeros and $$$n - k$$$ ones.</p><p>For each vertex, we define the <span class="tex-font-style-it">name</span> of the vertex as the binary string formed by concatenating the labels of the vertices from the root to the vertex. Your task is to determine the maximum beauty among all labelings of the tree with exactly $$$k$$$ zeros and $$$n - k$$$ ones.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A sequence $$$a$$$ is a subsequence of a sequence $$$b$$$ if $$$a$$$ can be obtained from $$$b$$$ by the deletion of several (possibly, zero or all) element from arbitrary positions.  The longest common subsequence of strings $$$s_1, s_2, \ldots s_m$$$ is the longest string that is a subsequence of all of $$$s_1, s_2, \ldots, s_m$$$.</p><p>$$$^{\text{†}}$$$A leaf is any vertex without children. </p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. 1$$$ integers $$$p_2, p_3, \ldots, p_{n}$$$ ($$$1 \leq p_i \le i - 1$$$) — the parent of vertex $$$i$$$.</p><p>Note that there are <span class="tex-font-style-bf">no constraints</span> on the sum of $$$n$$$ over all test cases.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, output a single integer representing the maximum beauty among all labelings of the tree with exactly $$$k$$$ zeros and $$$n -
