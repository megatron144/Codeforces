## Problem Statement

<div class="header"><div class="title">C. XOR Problem</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>  </p><p>You are given an integer $$$n$$$.</p><p>Define the <span class="tex-font-style-it">beauty</span> of an array $$$a$$$ as the value of $$$|a| - f(a)$$$, where $$$|a|$$$ is the length of $$$a$$$ and $$$f(a)$$$ is the number of non-empty subarrays$$$^{\text{∗}}$$$ of $$$a$$$ with bitwise XOR equal to $$$0$$$. Formally, $$$f(a)$$$ is the number of pairs $$$(l, r)$$$ such that $$$1 \le l \le r \le |a|$$$ and $$$a_l \oplus a_{l + 1} \oplus \ldots \oplus a_r = 0$$$$$$^{\text{†}}$$$.</p><p>Among all arrays $$$a$$$ consisting of integers from $$$0$$$ to $$$n$$$ that have the maximum possible beauty, find one with maximum length.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$An array $$$c$$$ is a subarray of an array $$$d$$$ if $$$c$$$ can be obtained from $$$d$$$ by the deletion of several (possibly, zero or all) elements from the beginning and several (possibly, zero or all) elements from the end. Two subarrays are considered different if the sets of <span class="tex-font-style-bf">positions</span> of the deleted elements are different.</p><p>$$$^{\text{†}}$$$$$$\oplus$$$ denotes the <a href="https://en.wikipedia.org/wiki/Bitwise_operation#XOR">bitwise XOR operation</a>.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows.</p><p>The only line of each test case contains a single integer $$$n$$$ ($$$1 \le n \le 2 \cdot 10^5$$$) — the upper bound on the elements of the array.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, output a single integer $$$k$$$ — the length of the array. On the next line, output $$$k$$$ integers $$$a_1, a_2, \ldots, a_k$$$ ($$$0 \le a_i \le n$$$) — the elements of the array.</p><p>It can be shown that under the given constraints the sum of $$$k$$$ over all test cases does not exceed $$$10^6$$$.</p><p>If there are multiple suitable arrays, output any of them.</p></div><div class="sample-tests"><div class="section-title">Example</div><div class="sample-test"><div class="input"><div class="title">Input<div title="Copy" data-clipboard-target="#id007528588829470186" id="id0020414077393561492" class="input-output-copier">Copy</div></div><pre id="id007528588829470186"><div class="test-example-line test-example-line-even test-example-line-0">2</div><div class="test-example-line test-example-line-odd test-example-line-1">1</div><div class="test-example-line test-example-line-even test-example-line-2">2</div></pre></div><div class="output"><div class="title">Output<div title="Copy" data-clipboard-target="#id005006053839535962" id="id003670952690415047" class="input-output-copier">Copy</div></div><pre id="id005006053839535962">3

</pre></div></div></div><div class="note"><div class="section-title">Note</div><p>In the first example, $$$n = 1$$$, so every element of the array is equal to $$$0$$$ or $$$1$$$. One possible solution is $$$a = [1, 1, 1]$$$: it has exactly two subarrays with bitwise XOR equal to $$$0$$$, namely $$$(l, r) = (1, 2)$$$ and $$$(l, r) = (2, 3)$$$. These two subarrays consist of the same elements, but they occupy different positions, so both of them are counted, and the beauty of $$$a$$$ is $$$3 - 2 = 1$$$. It can be proven that every array of length $$$4$$$ with elements equal to $$$0$$$ or $$$1$$$ has at least four subarrays with bitwise XOR equal to $$$0$$$, so its beauty is at most $$$0$$$.</p><p>In the second example, one possible solution is $$$a = [2, 2, 1, 0, 2, 0, 1]$$$. Its subarrays with bitwise XOR equal to $$$0$$$ are $$$(l, r) = (1, 2)$$$, $$$(2, 7)$$$, $$$(4, 4)$$$, and $$$(6, 6)$$$, so the beauty of $$$a$$$ is $$$7 - 4 = 3$$$. The array $$$[1, 2, 2, 1, 2]$$$ has beauty $$$5 - 2 = 3$$$ as well, but it is shorter. It can be shown that $$$3$$$ is the maximum possible beauty for $$$n = 2$$$, and that no array of length greater than $$$7$$$ achieves it.</p></div>
